# Contributing

Contributions to Cadence's original code are accepted under GPL-3.0-only. Only submit work you have the right to contribute. Keep third-party copyright and license notices intact; identify external sources and modifications explicitly. No copyright assignment, CLA or DCO is required by this project.

Describe the problem, the resulting behaviour and relevant tests. Include French and English interface text when changing user-facing controls. Keep identifiers in English and reserve comments for constraints or decisions that are not apparent from the code.

Use synthetic media for tests. Do not submit recordings, logs, project files or screenshots containing private information without permission. Never commit credentials, signing keys, generated binaries or dependency caches.

Run the relevant tests and the build checks in docs/BUILD.md. Tests of GPU display, capture, audio devices and 3D integration also require manual verification on the appropriate applications and hardware. Headless success does not replace those checks.

The project currently has one maintainer, who also reviews changes and approves releases. Public repository and contact links will be added after publication is approved.
