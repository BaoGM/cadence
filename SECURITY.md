# Security

This is a local publication candidate. A private vulnerability reporting channel has not yet been configured. Do not post credentials, private media, exploit details or personal diagnostic logs in public issues. Private reporting must be configured before public release.

Only open media and projects from sources you trust. Cadence delegates media parsing to PyAV and FFmpeg. Keep the application and its dependencies updated.

The optional 3D integration listens on a loopback TCP endpoint and uses a per-session token. It does not intentionally expose a remote control service to other computers. Other processes running under the same Windows account can read the local endpoint file, so this is not isolation from untrusted software running as that user.

The integration installs startup connectors in Blender/Maya user directories after activation. Drawing transfers can create or remove objects tagged as Cadence-owned. Keep backups of important 3D scenes.

Build and release jobs must not execute untrusted contributions with signing credentials. Production signatures require manual approval. The unsigned build workflow uses read-only repository permissions and has no signing secret.
