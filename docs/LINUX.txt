Cadence 1.17.0 — Linux beta / bêta Linux

FRANÇAIS
Ubuntu Desktop 24.04, processeur x86_64 (Intel/AMD 64 bits).
Extraire toute l'archive dans un dossier personnel, puis lancer le fichier Cadence.
Dans un terminal : ./Cadence
Ne pas lancer Cadence avec sudo. Conserver le dossier _internal à côté du programme.
Pré-requis : libxcb-cursor0, xdg-utils, desktop-file-utils, shared-mime-info.
La capture audio nécessite PipeWire/PulseAudio et pulseaudio-utils.
Si nécessaire : sudo apt install libxcb-cursor0 xdg-utils desktop-file-utils shared-mime-info pulseaudio-utils

Lecture, édition, dessin, projets et export sont disponibles.
Capture : session X11 (choisir « Ubuntu sur Xorg » à la connexion), écran ou zone,
MP4/GIF, curseur et indications clavier/clics. Ctrl+Maj+F8 démarre/arrête la capture.
Le son utilise la sortie et le microphone par défaut disponibles dans Ubuntu.
Fichier > Associer enregistre Cadence dans « Ouvrir avec » ; le choix par défaut
reste dans les propriétés des fichiers d'Ubuntu. En cas de déplacement du dossier
ou de mise à jour, refaire l'association depuis le nouvel emplacement.

Limites de cette bêta : capture Wayland et intégration 3D indisponibles.
Le rendu utilise OpenGL avec repli logiciel. Le décodage matériel Linux et les
performances sur une carte graphique physique ne sont pas encore validés.
Les tests audio ont utilisé une sortie virtuelle ; le microphone physique reste à vérifier.
Les autres distributions, ARM64 et Ubuntu antérieures à 24.04 ne sont pas validées.

Mises à jour : Aide > Rechercher des mises à jour. Activer les versions de test
dans les préférences pour recevoir les préversions Linux. L'archive téléchargée
est vérifiée puis extraite manuellement dans un nouveau dossier. Les préférences
restent dans ~/.config/CadenceStudio (ou XDG_CONFIG_HOME).

Code Cadence : GPL-3.0-only. Sources exactes dans Licences/Cadence-sources.zip.
Les licences et sources tierces conservent leurs conditions propres ; voir
Licences/NOTICE.txt et Licences/THIRD-PARTY-SOURCES.txt.

ENGLISH
Target: Ubuntu Desktop 24.04, x86_64. Extract the complete archive into a user
directory and run ./Cadence. Keep _internal next to the executable; do not use sudo.
Runtime packages: libxcb-cursor0, xdg-utils, desktop-file-utils, shared-mime-info;
audio recording also needs PipeWire/PulseAudio and pulseaudio-utils.
Screen recording requires an X11 session (Ubuntu on Xorg). Ctrl+Shift+F8 starts/stops.
File > Associate registers Open With support; choose defaults in Ubuntu file properties.
Register again after moving or replacing the application directory.
Wayland recording, 3D integration, hardware video decoding, physical GPU performance,
physical microphone input and other distributions/architectures are not validated.
Enable test versions in preferences to receive Linux previews. Updates download a
verified archive to extract into a new directory; your preferences are retained.
Cadence is GPL-3.0-only. Exact sources and license notices are under Licences.
The separately published third-party source archives are listed in
Licences/THIRD-PARTY-SOURCES.txt; extract all ZIP parts into the same directory.
